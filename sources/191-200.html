  • D. インスタンスの詳細な監視を設定します。StatusCheckFailed_Instance メトリック用の Amazon CloudWatch アラームを作成します。ディメンションとして EC2 Amazon Machine Image (AMI) ID を使用します。メトリック値がゼロより大きい場合に、EC2 インスタンスの停止操作と EC2 インスタンスの開始操作を実行するようにアラームを設定します。
