企業は、自社のメインのAWS本番アカウントで新しいAmazon EC2インスタンスが起動した際に、即座にメール通知を受け取る必要があります。

この要件を満たすソリューションはどれでしょうか？

  • A. SMTPメールリレー経由で電子メールメッセージを送信するユーザーデータスクリプトを作成します。ユーザーデータスクリプトの受信者として、会社のメールアドレスを含めます。標準化されたビルドプロセスの一環として、すべての新しいEC2インスタンスにユーザーデータスクリプトが含まれるようにします。
  • B. Amazon SNSトピックを作成します。AWS Systems Managerを設定して、EC2イベントをSNSトピックに発行します。AWS Lambda関数を作成してSNSトピックをポーリングします。Lambda関数を設定して、会社のメールアドレスにメッセージを送信します。
  • C. Amazon SNSトピックと、メールプロトコルを使用するサブスクリプションを作成します。サブスクライバーとして会社のメールアドレスを入力します。EC2インスタンスの起動時に反応するAmazon EventBridgeルールを作成します。ルールのターゲットとしてSNSトピックを指定します。
  • D. Amazon SNSトピックと、メールプロトコルを使用するサブスクリプションを作成します。サブスクライバーとして会社のメールアドレスを入力します。EC2インスタンスの起動時にイベントターゲットとしてSNSトピックを指定するには、EC2 AssociateInstanceEventWindow操作を使用します。

トンネルが利用できなくなった場合に即座に通知を受け取るための自動監視ソリューションを導入する必要があります。

この要件を満たす手順の組み合わせはどれですか？（2つ選択してください。）

  • A. Amazon CloudWatch Logs を使用して VPN 収集ログを収集および保存します。ログを読みやすいメトリクスに変換します。VPN トンネルのメトリクスをログからフィルタリングするためのメトリクスフィルタを作成します。
  • B. AWS CloudTrail を使用して VPN ログを収集します。ログは Amazon S3 バケットに保存します。Amazon Athena を使用してデータをクエリし、サイト間 VPN トンネル接続エラーを検出します。エラー ファイルは別の S3 バケットに保存します。

  • D. Amazon EventBridge ルールを使用して AWS Lambda 関数を呼び出します。VPN トンネル接続エラーが検出されたときに Amazon SNS を使用して通知を送信するように Lambda 関数を設定します。
  • E. AWS Systems Managerを使用してVPNトンネルを管理し、VPNトンネルの接続エラーを監視します。

企業は、問題のあるデータベース変更をできるだけ早く元に戻したいと考えています。また、RDS for MySQL から Amazon Aurora MySQL 互換エディションのクラスターへの移行を検討しています。

  • D. Auroraクラスターの前にRDSプロキシを作成します。更新が失敗した場合は、DBスナップショットを復元し、RDSプロキシを変更して新しいDBクラスターエンドポイントを使用するようにします。

CloudOps エンジニアは、Amazon EC2 リソースと Amazon RDS リソースのバックアップ戦略を実装する必要があります。バックアップ戦略は、次の保持要件を満たす必要があります。

• 日次バックアップ: 6 日間保持する必要があります
• 週次バックアップ: 4 週間保持する必要があります
• 月次バックアップ: 11 か月保持する必要があります
• 年次バックアップ: 7 年間保持する必要があります

これらの要件を最小限の管理作業で満たすバックアップ戦略はどれですか。

  • A. Amazon Data Lifecycle Managerを使用して、Amazon EBSスナップショットポリシーを作成します。バックアップが必要な各リソースにタグを作成します。ポリシー内の要件に応じて複数のスケジュールを作成します。適切な頻度と保持期間を設定します。
  • B. AWS Backup を使用して、各保持要件ごとに、バックアップ頻度を日次、週次、月次、または年次で設定した新しいバックアップ プランを作成します。保持期間を要件に合わせて設定します。バックアップが必要な各リソースにタグを作成します。タグを使用してリソースの割り当てを設定します。
  • C. AWS Lambda 関数を作成します。Lambda 関数に、ネイティブツールを使用して Amazon EC2 のファイルシステムのバックアップを取得し、Amazon RDS のデータベースのコピーを作成するようにプログラムします。Lambda 関数を呼び出す Amazon EventBridge ルールを作成します。
  • D. Amazon Data Lifecycle Manager を使用して、Amazon EBS スナップショット ポリシーを作成します。バックアップが必要な各リソースにタグを作成します。タグを使用してリソースの割り当てを設定します。ポリシー内の要件に応じて複数のスケジュールを作成します。適切な頻度と保持期間を設定します。Amazon RDS で、必要な DB インスタンスの自動バックアップを有効にします。

これらの要件を満たすソリューションはどれでしょうか？
