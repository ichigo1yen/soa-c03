質問#051

開発者は、Amazon Linux Amazon Machine Image (AMI) を使用して、サードパーティ製アプリケーションをホストする EC2 インスタンスを起動します。アプリケーションが時折不安定になることがあります。CloudOps エンジニアは、使用率が 15 分間 90% を超えた場合に EC2 インスタンスを自動的に再起動し、再起動について開発者に通知するソリューションを必要としています。
管理作業を最小限に抑えつつ、これらの要件を満たすソリューションはどれでしょうか？

  • A. インスタンスの CPU 使用率を評価する Amazon CloudWatch アラームを設定します。アラームがアクティブになったときに、AWS Lambda 関数を呼び出して Amazon Simple Notification Service (Amazon SNS) トピックにメッセージを送信するようにアラームを設定します。Lambda 関数を設定して EC2 インスタンスを再起動します。開発者を SNS トピックに登録します。
  • B. インスタンスの CPU 使用率を評価する Amazon CloudWatch アラームを作成します。アラームを設定して、Amazon Simple Notification Service (Amazon SNS) トピックに通知を発行し、インスタンスを再起動する EC2 アクションを実行します。開発者を SNS トピックに登録します。
  • C. インスタンスの CPU 使用率を評価する Amazon CloudWatch アラームを作成します。アラームを設定して、AWS Systems Manager アクションを呼び出し、インシデントを作成して開発者に通知し、再起動を要求します。
  • D. Amazon Simple Notification Service (Amazon SNS) トピックにメッセージをパブリッシュし、EC2 インスタンスを再起動する AWS Systems Manager ランブック スクリプトを作成します。開発者を SNS トピックに登録します。インスタンスの CPU 使用率が 15 分以上 90% を超えた場合に Systems Manager ランブックを実行するように Amazon CloudWatch アラームを設定します。

  • B. VPC で DNS 解決オプションと DNS ホスト名オプションが無効になっていることを確認します。Amazon S3 用のゲートウェイ VPC エンドポイントを作成します。CloudWatch Synthetics が S3 エンドポイントを使用できるように、権限を追加します。
  • C. VPでDNS解決オプションとDNSホスト名オプションがオフになっていることを確認します。カナリアにセキュリティグループを追加して、DNSポートでの送信トラフィックを許可します。CloudWatch SyntheticsがS3バケットに書き込めるように権限を追加します。
